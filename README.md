# CloudForge

## Project Overview

CloudForge is an automated cloud infrastructure deployment
and management project built using AWS, Terraform, Docker,
GitHub Actions, and Linux.

The project demonstrates Infrastructure as Code (IaC),
Continuous Integration and Continuous Deployment (CI/CD),
automated testing, deployment workflows, and cloud security.

## Objectives

- Provision AWS infrastructure using Terraform.
- Containerize the application using Docker.
- Automate testing using GitHub Actions.
- Implement controlled deployment workflows.
- Apply security and cost-management practices.
- Document infrastructure and deployment procedures.

## Technology Stack

- AWS
- Terraform
- Linux (Ubuntu)
- Docker
- Git and GitHub
- GitHub Actions
- Python
- Bash

## Project Structure

- application/ — Application source code
- terraform/ — Infrastructure as Code
- docker/ — Container configuration
- scripts/ — Automation scripts
- architecture/ — Architecture diagrams
- docs/ — Technical documentation
- screenshots/ — Project evidence
- .github/workflows/ — CI/CD workflows

## Cost Management

AWS resources will be created only after reviewing
the expected costs and receiving approval.

Infrastructure will be monitored and cleaned up
after approved lab sessions.
